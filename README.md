# Крестики-нолики по ПЗшному

Web-ремейк одноимённой мини-игры 2006 года в стиле «Проклятых Земель» (Evil
Islands). Оригинал был написан на Delphi, исходники утеряны — эта версия
воссоздана из самого исполняемого файла: вся графика, тексты и геометрия окон
извлечены из ресурсов `Krestiki.exe`.

Классические крестики-нолики 3×3 против компьютера:

- **Легкий** — выигрывает, если может, иначе блокирует вашу линию, иначе ходит случайно;
- **Тяжелый** — идеальная стратегия (минимакс): не проигрывает вообще;
- можно выбрать, кто ходит первым — вы («Я») или компьютер («Комп»).

**Играть онлайн:** <https://fatfaldog.github.io/ei-tic-tac-toe/>
(адрес начнёт отвечать после включения GitHub Pages — см. ниже).

## Локальный запуск

Никакой сборки и зависимостей: откройте `web/index.html` в любом браузере —
игра полностью автономна и работает даже с диска (`file://`).

## Включение GitHub Pages (один раз)

Публикацией управляет воркфлоу [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml):
при пуше в `main` он выкладывает содержимое `web/` (без тестовых страниц
`web/tests/`) на Pages. Чтобы он заработал, включите Pages:

1. Откройте репозиторий на GitHub:
   <https://github.com/fatfaldog/ei-tic-tac-toe>
2. **Settings** → левое меню **Code and automation** → **Pages**.
3. В блоке **Build and deployment**, поле **Source**, выберите **GitHub Actions**
   (не «Deploy from a branch»).
4. Готово — настройка применяется сразу, сохранять не нужно.
5. Запустите публикацию: вкладка **Actions** → слева workflow
   **Deploy to GitHub Pages** → справа **Run workflow** → кнопка
   **Run workflow** (ветка `main`). Дождитесь зелёной галочки (1–2 минуты).
6. Откройте <https://fatfaldog.github.io/ei-tic-tac-toe/> — там должна быть игра.

Если пункт 5 пропустить, публикация всё равно случится при следующем пуше
в `main`, затрагивающем `web/`.

> Первый прогон воркфлоу до включения Pages (пункт 3) закончится красным —
> это ожидаемо; после включения просто запустите его снова.

## Как обновляется сайт

Изменения в `web/`, запушенные в `main`, автоматически переиздаются. Правки
`openspec/`, `tools/`, `old_compiled/` сайт не пересобирают — триггер
воркфлоу настроен только на `web/**` и на сам файл воркфлоу.

Проверить, что публикуется только игра:

```
curl -s -o /dev/null -w '%{http_code}\n' https://fatfaldog.github.io/ei-tic-tac-toe/                  # 200
curl -s -o /dev/null -w '%{http_code}\n' https://fatfaldog.github.io/ei-tic-tac-toe/tests/engine-tests.html  # 404
```

## Встраивание в сайт (iframe)

Игра — автономная статика без сборки и внешних запросов, GitHub Pages
не запрещает встраивание (нет `X-Frame-Options`), поэтому её можно вставить
в любую страницу обычным iframe:

```html
<iframe
  src="https://fatfaldog.github.io/ei-tic-tac-toe/"
  width="419" height="460"
  style="border:0"
  title="Крестики-нолики по ПЗшному"
  allow="gamepad"
></iframe>
```

Нюансы:

- **Клавиатура** оживает после первого клика внутри iframe — до этого
  нажатия достаются странице-хозяину.
- **Геймпад** в кросс-доменном iframe по умолчанию выключен браузером
  (Permissions-Policy) — атрибут `allow="gamepad"` это снимает.
- **Размер**: игровое окно 417px + рамка, по высоте ~440px; при iframe
  меньше ~420×455 появятся скроллбары.
- **Границы**: модальные окна, курсор и вся клавиатура живут внутри
  iframe и не выходят на страницу-хозяина; пункт «Выход» в iframe не может
  закрыть вкладку и показывает прощальный экран — это предусмотрено.
- **Своя копия**: можно положить каталог `web/` на любой хостинг (игра
  работает даже с `file://`) и указать в `src` свой адрес.

## Структура репозитория

```
web/            игра: index.html, css/, js/, assets/ (графика из exe), tests/
old_compiled/   исходный Krestiki.exe и DLL (только чтение, в публикацию не входит)
tools/          скрипты извлечения ассетов из exe и прогона тестов
openspec/       спецификации и история изменений (OpenSpec)
```

Тесты: `node tools/run_tests.js web/tests/engine-tests.js web/tests/ai-tests.js web/tests/input-tests.js`
(43 проверки логики), `node tools/ui_smoke.js` (99 проверок интерфейса);
в браузере — `web/tests/engine-tests.html` и `web/tests/ai-tests.html`.
