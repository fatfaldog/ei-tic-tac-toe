# Proposal

## Why

Окно «Об авторе» называет людей и первоисточники, но не говорит, где лежит сама игра: репозиторий GitHub — единственная точка, откуда проект распространяется и принимается вклад, а ссылки на него в игре нет.

## What Changes

- В окне «Об авторе», над блоками «Разработка»/«Тестирование», появляется блок на всю ширину двух колонок (в стиле остальных групп — с подложкой) со ссылкой на репозиторий `https://github.com/fatfaldog/ei-tic-tac-toe/` (новая вкладка).
- Текст ссылки — «Репозиторий игры на GitHub» (допущение; URL виден в статус-баре/href).
- Ссылка участвует в Tab-порядке окна первой (до ссылки на «Вселенную Аллодов» и плиты-галочки); окно остаётся модальным.

## Capabilities

(нет)

### Modified Capabilities

- `game-ui` — «Окно «Об авторе»»: добавляется блок со ссылкой на репозиторий над авторским и тестерским блоками.

## Impact

- Код: `web/index.html` (новая группа-блок перед `.about-top`), `web/css/style.css` (центровка/растяжение блока на две колонки).
- Тесты: смоук — проверка наличия ссылки и её адреса в разметке.
- Совместимость: без изменений поведения окна; вкладка модальности и порядок Tab расширяются естественным образом (DOM-порядок).
