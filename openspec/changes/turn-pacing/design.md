# Design

## Context

См. proposal.md — Why. Движок (`Game`) синхронно эмитит `move`(игрок) → `move`(компьютер) → возможно `gameover` в одном тике; UI (`onGameEvent`) рендерит мгновенно. Движок и 43 логических теста — неприкасаемы. Строка состояния — новая полоса внизу `game-area`; окно подрастёт, скейлер fit-to-viewport мерит из DOM и подстроится сам.

## Goals / Non-Goals

**Goals:**
- Живой темп: 2с «думаю» + 1с проявление, единый для десктопа/мобилки/iframe.
- Рассинхрон движка и картинки исключён в принципе.

**Non-Goals:**
- Тайминги в движке, асинхронный ИИ — темп чисто UI.
- Анимация линии победы, звук, «рука» рисующая знак — отдельные темы.
- Разные задержки для уровней сложности.

## Decisions

1. **Очередь визуализации в ui.js, движок чистый.** `onGameEvent('move')`: ход игрока — рендер сразу (класс `draw-in`) + статус «рисую»; ход компьютера — в `pendingMove` + таймер DRAW_MS (дорисовался знак игрока). По таймеру: рендер знака компьютера с `draw-in`, таймер DRAW_MS → статус «ваш ход», разблокировка. `gameover` — в `pendingResult`, показывается когда очередь пуста. Искусственное «думанье» 2с убрано правкой приёмки: вычисление мгновенно, динамику дают последовательные анимации; статус «думаю…» исключён из словаря.
2. **Блокировка ввода — флаг `visualLock`.** Гард в `tryMove()` (клики и confirmCell идут через него). Навигация фокуса/цифры-выбор клетки не блокируются (безвредно), блокируется только попытка хода. Движок не вызывается — рассинхрона нет by construction.
3. **Таймеры — собираем и гасим.** Иды таймеров в массиве; `newgame` → `clearTimeout` всех, очередь пуста, статус по `first` (игрок — «ваш ход», компьютер — «думаю…» и первый ход компьютера пойдёт той же очередью, т.к. движок эмитит его синхронно при `newGame()`).
4. **fadein — CSS-класс.** `renderCell` вешает `draw-in` (`opacity: 0 → 1`, `transition: opacity 1s`), класс снимается по `transitionend`/таймеру, чтобы пере-рендер клетки не переигрывал анимацию. `@media (prefers-reduced-motion: reduce)` — transition отключён (знак появляется сразу), тексты/задержки остаются.
5. **Строка состояния**: `div#status-bar` внутри `game-area` (absolute, bottom, по центру), ~11px, цвет #c8a874 (палитра номеров клеток), тень как у мелких надписей. `renderStatus(text)` — единственная точка записи.
6. **Смоук: управляемые таймеры.** Стаб `setTimeout` превращается в очередь `windowStub._timers` (push {id, fn, delay}) + `windowStub.flushTimers()` исполняет по порядку; `clearTimeout` убирает из очереди. Существующие проверки (мгновенный мир) прогоняются с авто-flush после каждого действия обёрткой — либо, проще: оставить старый синхронный режим по умолчанию и включать отложенный режим явным флагом только в новых тестах темпа. Выбираю второе: нулевой риск для 135 существующих проверок.
7. **Тайминги константами** `THINK_MS = 2000`, `DRAW_MS = 1000` (экспорт для тестов), числа согласованы со спекой.

## Risks / Trade-offs

- Партия стала длиннее по времени (~3с на обмен) — это и есть цель; «Легкий»/«Тяжелый» тем же темпом.
- `transitionend` не стреляет на `display:none`/reduced-motion — снятие класса дублируем таймером DRAW_MS.
- Быстрые «Новая игра» подряд — все пути гасят таймеры через единую точку сброса.
