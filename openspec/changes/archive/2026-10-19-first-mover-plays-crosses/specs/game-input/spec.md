# Spec Delta

## MODIFIED Requirements

### Requirement: Индикация фокуса
Текущая клетка в фокусе SHALL отображать индикацию: пустая клетка в очередь игрока — тёплое свечение и полупрозрачный призрак текущего знака игрока (крестика, если игрок ходит первым, нолика — если вторым); пустая клетка в очередь компьютера — свечение без призрака; занятая клетка — красную подсветку, показывающую недопустимость хода.

#### Scenario: Призрак на пустой клетке
- **WHEN** в очередь игрока фокус на пустой клетке
- **THEN** клетка светится и показывает полупрозрачный текущий знак игрока — крестик или нолик

#### Scenario: Занятая клетка
- **WHEN** фокус на клетке с любым знаком
- **THEN** подсветка красная, призрак не показывается

#### Scenario: Очередь компьютера
- **WHEN** фокус на пустой клетке в очередь компьютера
- **THEN** клетка светится без призрака, ход по подтверждению не выполняется
