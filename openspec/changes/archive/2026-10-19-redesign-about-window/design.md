# Design

## Context

`references/about.png` — 2170×725, плита с вплавленным текстом на белом фоне (углы RGB≈255; есть и чёрные поля). Текущее окно: `about-bg.jpg` (344×384, «крыс» — фон-существо) + Memo-текст 2006 г. поверх. Диалог «Настройки» задал паттерн: тёмная панель 404×410, плита-заголовок (`plate-settings.png`, альфа по теплоте), рамка, плиты `plate-confirm.png`/`plate-cancel.png` внизу.

## Goals / Non-Goals

**Goals:**
- Окно «Об авторе» структурно = «Настройки» (плита → рамка → одна плита OK).
- Новый современный текст с оговорёнными именами и ссылкой.
- Переиспользование готовых плит и фона; единственный новый ассет — заголовочная плита.

**Non-Goals:**
- Кликабельность ссылки (окно информационное; адрес отображается текстом).
- Изменение меню, настроек, игры.

## Decisions

### D1. Срез плиты `about.png`: альфа по небелому-нечёрному
Белый фон ~RGB(255) и чёрные поля — оба чисто ахроматические, плита — тёплая/тёмная фактура. Альфа: 1 − max(clamp((255−lum−?)/…) для белого, clamp(lum/…) для чёрного) — т.е. alpha = min(отбел, отчерн): белый/чёрный → 0, фактура плиты → 1 с мягкими краями. Границы — по градиентам (как у плит настроек), кроп до контента.

### D2. Макет = настройки, минус список
`.modal.about`: панель 404×410, те же стили панели. Заголовок — `plate-about.png` (`contain`, ~340px ширины). Рамка высотой ~230px с фоном `about-bg.jpg` (cover по ширине, существо по центру). Текст — те же полупрозрачные строки-подложки, что у настроек (читабельность на фоне-крысе), выравнивание по центру. Внизу — центрированная `plate-confirm.png` (reuse, id `about-ok`), текст «✔» не нужен (символ вплавлен).

### D3. Текст (современная редакция) — в `ui.js`, layout.json уходит из поставки
Строки: «Автор — fatfaldog», «Тестирование — PPyatachok», «Отдельная благодарность: ksaont, Morgens и проекту "Вселенная Аллодов"», «allods.gipat.ru». Хранится константой в `ui.js`. `layout.json` — дев-инвентарь (игрой не читается: file:// без fetch), переезжает из `web/assets/` в корень репо; экстрактор пишет по новому пути, `ui_smoke` читает оттуда; старый текст Memo остаётся только в истории git.

### D4. Контекст `about`: одна позиция
`handleAction('about')`: CONFIRM — закрыть (фокус всегда на плите, kbd-active), BACK — закрыть. Мышь: клик по плите закрывает, клик по фону — нет (информационное). Угловая ✕-кнопка удаляется вместе со старыми стилями Memo.

## Risks / Trade-offs

- [Срез плиты по белому фону может оставить ореол] — пороги мягкие (рампа), как у plate-settings; проверка ASCII-рендером.
- [Пропорции about.png (3:1) против настроечной (5.3:1)] — `contain` в слоте 340×63 ужмёт высоту; при визуальном провале — кроп левых/правых полей плиты.

## Migration Plan

Инструмент среза → ассет → разметка/CSS → ui.js (контекст, текст) → смоук → пуш. Откат — git revert.
