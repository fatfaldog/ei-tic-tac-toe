# Proposal

## Why

README отстал от жизни после дня активной разработки: раздел «Структура репозитория» не знает про `references/`, `layout.json`, `.github/` и `LICENSE`; описание `tools/` не покрывает нарезку плит; скобка у «Играть онлайн» обещает, что адрес «начнёт отвечать после включения Pages», хотя Pages давно работает; счётчик смоук-проверок отстал (99 вместо актуального), в списке браузерных тестов нет `input-tests.html`.

## What Changes

- **«Структура репозитория»**: добавить `references/` (исходники-скриншоты плит), `layout.json` (дев-инвентарь координат из exe, в корне), `.github/` (воркфлоу деплоя), `LICENSE`; уточнить описание `tools/` — извлечение из exe И нарезка плит из `references/`, плюс прогон тестов.
- **«Играть онлайн»**: убрать устаревшую скобку «адрес начнёт отвечать после включения GitHub Pages — см. ниже».
- **Счётчики тестов**: смоук — актуальное число на момент применения (сейчас 106), браузерные — добавить `web/tests/input-tests.html`.
- **Шапка**: короткое перечисление сегодняшних возможностей (номера клеток-подсказки, сохранение настроек в localStorage, диалоговое окно результата) — раздел про геймплей сейчас описывает только уровни ИИ и первый ход.
- **«Включение GitHub Pages (один раз)»**: пометка, что для этого репозитория шаг уже выполнен и раздел носит справочный характер (на случай пересоздания окружения).
