# Proposal

## Why

Игра полностью мышиная: ни одного `keydown` в коде, Gamepad API не используется. Полноценное управление с клавиатуры и геймпада делает игру доступнее, удобнее на телевизоре/диване и просто приятнее — при этом движок правил (`engine.js`) и ИИ не меняются: новый ввод подаёт те же вызовы, что и мышь.

## What Changes

- Новый слой ввода `web/js/input.js`: клавиатура и геймпад сводятся к единым действиям (вверх/вниз/влево/вправо/подтвердить/назад/меню), которые диспетчеризуются по текущему контексту UI (поле, меню, настройки, оверлеи, «Об авторе»).
- **Полный охват**: клавиатурой/геймпадом управляется всё — ходы на поле, меню «Игра» (открытие, навигация, выбор), окно «Настройки» (навигация по чекбоксам, переключение), оверлей результата, закрытие окон.
- **Единая модель фокуса**: наведение мыши и навигация клавиатурой/геймпадом двигают один и тот же фокус клетки — можно навигироваться мышью, а подтверждать с клавиатуры (и наоборот). Клик мышью работает как раньше (выбор + подтверждение одним действием).
- **Индикация фокуса**: тёплое свечение текущей клетки; на пустой клетке в очередь игрока — полупрозрачный призрак крестика (знака игрока); на занятой — красная подсветка «сюда нельзя»; в очередь компьютера — свечение без призрака.
- **Раскладка клавиш 1–9**: по умолчанию «читающая» (1 = верхний левый), переключается на «нумпадовую» (7 8 9 / 4 5 6 / 1 2 3) третьей группой в окне «Настройки»; применяется сразу.
- Геймпад: D-pad/стик (с мёртвой зоной), A — подтвердить, B — назад, Start — меню; опрос через Gamepad API с edge-детекцией нажатий.

## Capabilities

### New Capabilities
- `game-input`: управление игрой с клавиатуры и геймпада — действия, раскладки, единый фокус и его индикация, полная навигация UI.

### Modified Capabilities
- `game-ui`: окно «Настройки» получает третью группу выбора «Раскладка 1-9:» («Читающая»/«Нумпад») в стиле существующих групп.

## Impact

- Новые файлы: `web/js/input.js`, тесты `web/tests/input-tests.{js,html}`; изменяются `web/index.html` (подключение скрипта, третья группа настроек), `web/css/style.css` (подсветка/призрак/красная индикация, фокус чекбоксов и пунктов меню), `web/js/ui.js` (фокус-состояние и диспетчер), `tools/ui_smoke.js` (новые проверки).
- Движок, ИИ и спецификации `tic-tac-toe-game`/`computer-opponent` не меняются: ввод вызывает существующие `game.playerTurn()` и обработчики UI.
- Мышь не ломается: все существующие сценарии остаются.
- **Вне рамок** (осознанно): назначение знака по праву первого хода (идея «игрок играет ноликами, если ходит вторым») — призрак всегда крестик игрока; сохранение настроек между сессиями; экран переназначения клавиш; тач-жесты.
- Публикация на Pages обновится автоматически (изменения в `web/**`).
