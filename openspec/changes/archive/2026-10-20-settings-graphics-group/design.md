# Design

## Context

См. proposal.md. Сейчас: две группы («Геймплей», «Управление с клавиатуры»), четыре строки, рамка 240px без прокрутки. Движок хранит `{level, first, digitLayout, showDigits}`; темп/проявление — turn-pacing (`draw-in` 1с, `DRAW_MS`), `reducedMotion()` гасит анимацию по медиа-запросу.

## Goals / Non-Goals

**Goals:**
- Три группы по смыслу; новая строка «Анимация» управляет проявлением/темпом наравне с системной настройкой.
- Всё влезает: скролл рамки с прилипающими заголовками.

**Non-Goals:**
- Изменение геймплея, текстов темпа, логики сохранения (кроме нового поля).
- Горизонтальная адаптация окна.

## Decisions

1. **Поле `animate: true` в движке** — валидация boolean в `applySettings` (как `showDigits`), попадает в `saveStoredSettings`; старое хранилище без поля даёт умолчание Вкл.
2. **Единый гейт `animationsEnabled()`** = `game.settings.animate !== false && !reducedMotion()`: его проверяет `renderCell` (вешать ли `draw-in`) и тайминги темпа (пауза перед знаком компьютера и после него — DRAW_MS или 0). «Выкл» схлопывает обмен до мгновенного, статусы мелькают по фазам как положено.
3. **Разметка**: заголовки `set-group-game`/`set-group-graphics`/`set-group-kbd` (текст «Управление»); строки в порядке level, first | showDigits, animate | digitLayout; новая строка `set-row-animate`/`set-val-animate`.
4. **Позиции навигации**: строки 0–4, галочка 5, крестик 6 — те же механики (`SETTING_KEYS/ROW_IDS/VALUE_IDS`, `settingsPos`), только длины массивов; фокус-подсветка плит по позициям 5/6.
5. **Скролл**: `overflow-y: auto` на `.settings-frame`; заголовки `position: sticky; top: 0` с непрозрачным фоном рамки (`#0a0804`); в `renderSettings` выбранная строка — `scrollIntoView({block:'nearest'})` с гарда для тест-стаба. Скроллбар — 8px, тёплая фаска `#57492a` (стиль ПЗ).
6. **Смоук**: разметка трёх групп, цикл Вкл/Выкл, сдвиг индексов клавиатурной навигации (до «Порядка» — 4 вниз, плита OK — 5-я позиция), localStorage содержит `animate`, при «Выкл» знаки без `draw-in`.

## Risks / Trade-offs

- Прилипающие заголовки на непрозрачном фоне теряют просвет существа — фон рамки и так почти чёрный, потеря незаметна.
- Скролл колесом/свайпом в модалке — поведение браузера, ок.
