# Proposal

## Why

Игра — автономная статика без сборки, и её естественно встраивают в другие страницы через iframe; GitHub Pages не запрещает framing (нет `X-Frame-Options`/`frame-ancestors`). Но в README нет ни слова о встраивании: читатель вынужден сам догадываться про размеры iframe, геймпадный `allow="gamepad"` и поведение клавиатуры после клика.

## What Changes

- В `README.md` добавляется раздел «Встраивание в сайт (iframe)»: готовый сниппет (`width="419" height="460"`, `style="border:0"`, `title`, `allow="gamepad"`), место — после «Как обновляется сайт».
- В разделе фиксируются краткие пояснения: почему клавиатура оживает после первого клика в iframe; для геймпада в кросс-доменном iframe нужен `allow="gamepad"`; модальные окна и клавиатура не выходят за границы iframe; минимальный размер во избежание скроллбаров; альтернатива — положить копию `web/` на свой хост и указать свой путь (игра работает даже с `file://`).
- Попутно (тот же файл, та же правка): устаревшие счётчики тестов в разделе «Структура репозитория» обновляются с «24 логики / 18 интерфейса» на актуальные (43 логики / ~99 смоук).

- Риски: нет — чисто документационная правка.
