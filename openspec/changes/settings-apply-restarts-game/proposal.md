# Proposal

## Why

Сейчас галочка применяет настройки «к следующей новой партии»: текущая партия доживает свою жизнь. Если ходов ещё не сделано, это выглядит как «настройки не применились» (уровень, знак и первый ход остались старыми). Настройки геймплея должны вступать в силу сразу.

## What Changes

- Галочка (OK) при **изменённых настройках геймплея** (уровень сложности, право первого хода) применяет черновик и **сразу начинает новую партию**: поле очищается, знаки назначаются по новому праву первого хода, при «Комп» первым компьютер делает первый ход.
- Раскладка 1-9 — не геймплейная настройка: её изменение галочкой применяется немедленно (как сейчас), новую партию не начинает.
- Если геймплейные настройки не менялись (изменена только раскладка или ничего), новая партия не начинается — текущее состояние поля сохраняется.
- Крестик/Esc/B — без изменений: закрыть, отбросив черновик.

## Capabilities

### New Capabilities
(нет)

### Modified Capabilities
- `game-ui`: требование «Окно «Настройки»» — сценарий «Применение настроек» меняется на немедленный перезапуск партии при изменении геймплейных настроек.

## Impact

- Правятся: `web/js/ui.js` (`applySettingsOk` сравнивает черновик с текущими настройками по `level`/`first` и при различии вызывает новую партию), `tools/ui_smoke.js` (сценарии: геймплейное изменение → поле очищено/компьютер сходил; только раскладка → поле не тронуто).
- Спека `computer-opponent` («Право первого хода» — «настройка применяется к каждой новой партии») не меняется: новая партия и есть применение.
