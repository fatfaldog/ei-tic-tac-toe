# Spec Delta

## MODIFIED Requirements

### Requirement: Окно «Об авторе»
Игра SHALL предоставлять окно «Об авторе» в стиле диалогов «Проклятых Земель», структурно аналогичное окну «Настройки»: плита-заголовок «Об авторе» (срез из скриншота игры с прозрачным фоном), по центру — рамка с текстом на фоне-существе (`about-bg.jpg`), внизу — единственная плита с галочкой, закрывающая окно. Текст SHALL содержать: автора — fatfaldog, тестера — PPyatachok, отдельную благодарность — ksaont, Morgens и проекту «Вселенная Аллодов» со ссылкой https://allods.gipat.ru/. Esc/B SHALL закрывать окно.

#### Scenario: Показ окна «Об авторе»
- **WHEN** выбран пункт меню «Об авторе»
- **THEN** открывается окно с плитой «Об авторе», рамкой с фоном-существом и текстом и плитой галочки внизу

#### Scenario: Текст авторства
- **WHEN** окно открыто
- **THEN** текст называет автора fatfaldog, тестера PPyatachok и благодарит ksaont, Morgens и проект «Вселенная Аллодов» (allods.gipat.ru)

#### Scenario: Закрытие по галочке
- **WHEN** нажата плита с галочкой (или Esc/B)
- **THEN** окно закрывается, игра возвращается к партии
