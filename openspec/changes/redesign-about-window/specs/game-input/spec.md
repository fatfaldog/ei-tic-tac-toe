# Spec Delta

## MODIFIED Requirements

### Requirement: Полная навигация по интерфейсу
Клавиатурой и геймпадом SHALL управляться весь интерфейс: меню «Игра» — открытие (F10/M/Start), перемещение по пунктам стрелками, выбор Enter/A, закрытие Esc/B; окно «Настройки» — вертикальное перемещение стрелками по строкам списка и плиткам галочки/крестика, подтверждение циклит значение строки или нажимает плиту, Esc/B закрывает окно с отменой; окно «Об авторе» — фокус на плите галочки, Enter/A закрывает окно, Esc/B закрывает окно; оверлей результата — «Новая игра» по Enter/A; окна закрываются кнопкой назад. Мышь при этом продолжает работать во всех перечисленных местах.

#### Scenario: Меню с клавиатуры
- **WHEN** нажато F10, затем стрелка вниз и Enter на пункте «Настройки»
- **THEN** открывается окно «Настройки»

#### Scenario: Настройки с клавиатуры
- **WHEN** окно «Настройки» открыто, стрелки ведут к строке «Уровень сложности» и нажимается Enter
- **THEN** значение строки циклится, фон рамки переключается соответственно

#### Scenario: Подтверждение и отмена с клавиатуры
- **WHEN** в настройках стрелками выбрана плита с галочкой (или крестиком) и нажат Enter
- **THEN** настройки применяются (или отбрасываются), окно закрывается

#### Scenario: Об авторе с клавиатуры
- **WHEN** окно «Об авторе» открыто и нажат Enter (или Esc/B)
- **THEN** окно закрывается

#### Scenario: Закрытие окон
- **WHEN** открыто меню, окно «Настройки» или «Об авторе» и нажат Esc (или B на геймпаде)
- **THEN** оно закрывается (настройки — без применения), фокус возвращается к игре
