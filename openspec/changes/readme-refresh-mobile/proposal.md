# Proposal

## Why

README отстал на 26 коммитов и местами врёт: iframe-нюанс обещает скроллбары (скейлер давно вписывает игру в любую область), шапка не знает про темп и мобильность. Главное — позиционирование «воссоздана из exe, вся графика извлечена» больше не соответствует проекту: после 24 изменений это ремейк с переосмысленным UX/UI, а не порт.

## What Changes

- **Шапка README — честное позиционирование**: ремейк с переосмысленным UX/UI; сохранены оригинальная идея, игровая логика, дословные тексты исходов; часть ассетов переиспользована (фон, клетки, курсор); диалоги и взаимодействие спроектированы заново в визуальном языке «Проклятых Земель». Без жаргона («полевые ассеты» и т.п.).
- **Абзац фич в шапке**: + живой темп (строка состояния «Ваш ход. Жду...»/«Рисую...», анимации рисования знаков), + адаптивность (масштабирование под телефон и любой iframe).
- **iframe-нюанс «Размер»**: убрать ложь про скроллбары — игра автоматически масштабируется под размер iframe, сниппет 419×460 лишь один из вариантов.
- **game-ui Purpose** (одна фраза, прямой правкой): «сохраняющая стилизацию оригинала» → ремейк-формулировка в том же духе.
