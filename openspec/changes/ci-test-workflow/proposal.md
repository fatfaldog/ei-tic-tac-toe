# Proposal

## Why

162 проверки (43 логики + 119 смоук) выполняются только локально у автора — в репозитории нет автоматического прогона. Следствие видели сегодня трижды: ручные счётчики в README («43/99», «43/106») устаревают через часы после каждой правки и прямо сейчас снова неверны. Живой статус вместо мёртвой цифры — бейдж CI.

## What Changes

- Новый воркфлоу `.github/workflows/tests.yml`: прогон логических тестов и смоука на каждый пуш в `main` (по путям `web/**`, `tools/**` и самому файлу) и в PR; `concurrency` с `cancel-in-progress`, как у деплой-воркфлоу. Зависимостей нет — checkout + Node + две команды.
- README: бейдж Tests в абзаце про тесты; ручные числа проверок вычёркиваются (команды остаются — они сами печатают актуальные числа).

## Impact

- Код: новый `.github/workflows/tests.yml`, правка `README.md` (один абзац).

- Риски: первый ран может подождать в деградировавшей очереди GitHub — не блокер, статус виден по бейджу; не занимаем очередь устаревшими раннами (`cancel-in-progress`).
