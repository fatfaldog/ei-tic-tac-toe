# Spec Delta

## MODIFIED Requirements

### Requirement: Сообщение результата партии
По завершении партии игра SHALL явно сообщать игроку исход оригинальными текстами программы: победа игрока — «Вы выиграли. ПоЗдравляю!!!!!» (дословно, с врезанной аббревиатурой ПЗ); победа компьютера — «Комп вас уделал 😜» (в исходнике — код форумного смайлика «:tease:», в web-версии заменён на UTF-эмодзи-аналог); ничья — «Ничья!!!!» (дословно). Действие оверлея — запуск новой партии — SHALL оформляться каменной плитой «Новая игра» в стиле диалогов «Проклятых Земель» (срез `plate-new-game.png` из той же серии, что плита-заголовок «Об авторе»): с тенью, золотистым свечением при наведении и клавиатурном фокусе, с доступным текстовым именем «Новая игра»; клик, Enter и A нажимают её.

#### Scenario: Объявление исхода
- **WHEN** партия завершается победой одной из сторон или ничьей
- **THEN** игроку показывается сообщение с исходом партии

#### Scenario: Победа игрока
- **WHEN** игрок собирает линию из трёх крестиков
- **THEN** сообщение гласит «Вы выиграли. ПоЗдравляю!!!!!»

#### Scenario: Победа компьютера
- **WHEN** компьютер собирает линию из трёх ноликов
- **THEN** сообщение гласит «Комп вас уделал 😜»

#### Scenario: Ничья
- **WHEN** поле заполнено без победной линии
- **THEN** сообщение гласит «Ничья!!!!»

#### Scenario: Плита «Новая игра»
- **WHEN** показан оверлей результата
- **THEN** под текстом исхода видна каменная плита «Новая игра» (не текстовая кнопка); наведение и клавиатурный фокус подсвечивают её золотистым свечением, нажатие начинает новую партию
