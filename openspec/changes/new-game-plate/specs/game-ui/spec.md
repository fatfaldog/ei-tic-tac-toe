# Spec Delta

## MODIFIED Requirements

### Requirement: Сообщение результата партии
По завершении партии игра SHALL явно сообщать игроку исход оригинальными текстами программы: победа игрока — «Вы выиграли. ПоЗдравляю!!!!!» (дословно, с врезанной аббревиатурой ПЗ); победа компьютера — «Комп вас уделал 😜» (в исходнике — код форумного смайлика «:tease:», в web-версии заменён на UTF-эмодзи-аналог); ничья — «Ничья!!!!» (дословно). Оверлей результата SHALL оформляться окном в стиле диалогов «Проклятых Земель», структурно как «Настройки» и «Об авторе»: плита-заголовок «Результат» (срез `plate-result.png` из серии плит), под ней — рамка с текстом исхода, внизу — плита «Новая игра» (`plate-new-game.png`), запускающая новую партию. Подсветка плиты «Новая игра» при наведении и клавиатурном фокусе SHALL ограничиваться золотистым ореолом (без вспышки яркости всей плиты); клик, Enter и A нажимают её.

#### Scenario: Объявление исхода
- **WHEN** партия завершается победой одной из сторон или ничьей
- **THEN** игроку показывается окно результата с сообщением об исходе партии

#### Scenario: Победа игрока
- **WHEN** игрок собирает линию из трёх крестиков
- **THEN** сообщение гласит «Вы выиграли. ПоЗдравляю!!!!!»

#### Scenario: Победа компьютера
- **WHEN** компьютер собирает линию из трёх ноликов
- **THEN** сообщение гласит «Комп вас уделал 😜»

#### Scenario: Ничья
- **WHEN** поле заполнено без победной линии
- **THEN** сообщение гласит «Ничья!!!!»

#### Scenario: Окно результата в стиле диалогов
- **WHEN** показан оверлей результата
- **THEN** сверху видна плита-заголовок «Результат», в центре — рамка с текстом исхода, внизу — каменная плита «Новая игра» (не текстовая кнопка)

#### Scenario: Подсветка плиты «Новая игра»
- **WHEN** плита «Новая игра» hover'ится мышью или получает клавиатурный фокус
- **THEN** вокруг плиты появляется золотистый ореол как у плит галочки/крестика, без изменения яркости самой плиты; нажатие начинает новую партию
