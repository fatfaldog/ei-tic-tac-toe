# Design

## Context

Иконка сейчас — MAINICON из exe (32×32, 4 бита, стандартная Delphi-заглушка), подключена одной строкой в `index.html`. Нолик игры — `cell-a.jpg` (93×112, тёмный фон + светлое кольцо с орнаментом). Допущение (не спрашивал, оно очевидно): значок нолика выводим из этой текстуры, а не рисуем с нуля — аутентичность.

## Goals / Non-Goals

**Goals:**
- Favicon с узнаваемым ноликом в стиле игры; работает во вкладке и в закладках.
- Воспроизводимая генерация (инструмент в репо), как у остальных производных ассетов.

**Non-Goals:**
- Иконки для PWA/манифеста, apple-touch-icon (180×180 и пр.) — по запросу позже.
- Изменение текстуры нолика в игре.

## Decisions

### D1. Источник — `cell-a.jpg`, вырезание кольца
Центр текстуры ~(50, 50) содержит кольцо нолика (установлено пиксельной классификацией при порте). Квадратный кроп ~70×70 с центром в кольце → масштаб в 32×32 и 16×16.

### D2. Альфа по «теплоте» + яркости
Фон текстуры тёмный и холодный, кольцо — светлое тёплое (приём из plate-settings): альфа = max(clamp((lum − lo)/диапазон), clamp((G−B − lo)/диапазон)) — фон уходит в прозрачность, кольцо остаётся. На тёмной вкладке читается, на светлой — тоже (тёмная окантовка кольца остаётся полупрозрачной тёмной).

### D3. PNG первичен, ICO — откат
`<link rel="icon" type="image/png" href=".../favicon-32.png">` + второй тег с ICO (порядок: PNG сначала — современные браузеры берут первый подходящий; IE/старые берут .ico). Файлы: `favicon-32.png`, `favicon-16.png`, `favicon.ico` (двухслойный, собирается из тех же растров).

### D4. MAINICON уходит из поставки экстрактора
`extract_assets.py` прекращает писать `icon.ico` (аналогично курсорам: инвентаризация в layout.json остаётся, `shipped: false`). Новый инструмент `tools/make_favicon.py` — отдельный шаг сборки производных ассетов.

## Risks / Trade-offs

- [Кольцо мелкое на 16×16] — проверяем рендером; при необходимости для 16×16 кроп ближе/контрастнее.
- [Светлый фон вкладки] — тёмная окантовка полупрозрачна, проверяем визуально.

## Migration Plan

Инструмент → генерация файлов → index.html → экстрактор → git rm старого icon.ico → тесты/смоук → пуш. Откат — git revert.
