# Design

## Context

Текущие настройки — три пары кастомных чекбоксов (реплика VCL) с немедленным применением; фоны `settings-bg-1/2` наложены друг на друга, виден только верхний. Решения explore-режима: новый диалог по референсам `references/2_1.jpg`/`2_2.jpg` (плита-заголовок, список в рамке, плиты OK/X внизу); клик/Enter циклит значения; черновая семантика OK/X; существо в фоне рамки: «Легкий» → кролик (`settings-bg-2`), «Тяжелый» → тролль (`settings-bg-1`) — сверено с автором; окно в пределах игрового поля; Esc/B — отмена. Референсы — 1920x1080 скриншоты ПЗ: стиль переносится средствами CSS (тёмная панель, золото, плиты), ассеты не извлекаются.

## Goals / Non-Goals

**Goals:**
- Диалог в языке ПЗ: плита-заголовок, рамка-список, плиты OK/X.
- Черновик с живым превью фона-существа.
- Полная клавиатурно-геймпадная навигация новой модели.
- Возврат фишки кролик/тролль.

**Non-Goals:**
- Извлечение графики из референсов; новые ассеты (существа — существующие JPEG).
- Перенос окна в полноэкранный вид; размеры — в пределах окна игры (417px шириной).
- Изменение «Об авторе», меню, поля.

## Decisions

### D1. Структура и стиль диалога — CSS поверх тёмной панели
`.modal.settings` перерисовывается: тёмная полупрозрачная панель с золотой рамкой (как панели референсов); плита-заголовок «Настройки» — светлый прямоугольный блок с тиснением сверху; рамка списка — вложенный прямоугольник с золотой обводкой; плиты OK/X — каменно-золотые кнопки с символами галочки и крестика внизу. Палитра — уже используемая в игре (#14110a, #4a4128, #e8dcae, #c9bb92).

### D2. Существо — фон рамки списка, не всего окна
Рамка списка получает `background-image: settings-bg-2.jpg` (кролик) или `settings-bg-1.jpg` (тролль) по классу-модификатору `.hard`/`.easy`; переключение — обновление класса при цикле уровня в черновике (живое превью). Изображения ~348x321 в рамке ~ширины окна минус поля: `background-size: cover` по высоте рамки, по центру. Читаемость строк — полупрозрачная тёмная подложка под текстом строк (существо остаётся видно между строк и по краям).

### D3. Черновик: открытие → копия, OK → applySettings, X/Esc/B → отброс
`openSettings()` снимает копию `{level, first, digitLayout}` в `draft`; циклы меняют только `draft` (и класс существа); плита галочки вызывает `game.applySettings(draft)` и закрывает; крестик/Esc/B просто закрывают. `Game.applySettings` не меняется. Семантика «к следующей партии» сохраняется движком; раскладка после OK действует немедленно (как и раньше после applySettings).

### D4. Навигация: одна вертикаль 3 строки + 2 плиты
В контексте `settings` — пять позиций фокуса (3 строки, плита OK, плита X); UP/DOWN перемещают, CONFIRM циклит строку или нажимает плиту, BACK отменяет. Мышь: клик по строке циклит, по плите — действие. Подсветка фокуса — класс `kbd-active` (уже стилизован), для строк — дополнительно фон-строки.

### D5. Удаление старой механики
Из `index.html` удаляются `pz-label`/`pz-check` блоки и третья группа; из CSS — стили чекбоксов; из `ui.js` — `pair()` и `CHECK_IDS`-навигация; `tools/ui_smoke.js` — тесты настроек переписываются под новую модель (цикл, OK, X, превью существа по классу рамки, навигация).

## Risks / Trade-offs

- [Читаемость текста на тролле (bg-1 тёмный, но фактурный)] → тёмная полупрозрачная подложка строк; при приёмке поднять непрозрачность.
- [Асимметрия картинок (345/348 ширина)] → cover-масштабирование по рамке, существо центрируется.
- [Потеря `kbd-active` стилей чекбоксов] → стили переиспользуются для строк/плит.

## Migration Plan

Правки только в четырёх файлах (index.html, style.css, ui.js, ui_smoke.js); откат — git revert. Публикация на Pages — автоматически (web/**).
