# Proposal

## Why

Окно «Настройки» сейчас — буквальная копия VCL-чекбоксов 2006 года, не соответствующая диалоговому языку «Проклятых Земель» (референсы `references/2_1.jpg`, `references/2_2.jpg`: плита-заголовок, список в рамке, плиты-кнопки). Заодно при порте потерялась фирменная фишка оригинала — смена фонового существа по уровню сложности (тролль/кролик).

## What Changes

- Окно «Настройки» перерисовывается в стиле референсов: сверху плита-заголовок «Настройки»; под ней прямоугольник в рамке со списком настроек вида «название → текущее значение»; внизу две плиты — с галочкой (применить и закрыть) и крестиком (закрыть без применения). Окно в пределах игрового поля.
- Настройки — список из трёх строк: «Уровень сложности» (Легкий/Тяжелый), «Кто ходит первым» (Я/Комп), «Раскладка 1-9» (Читающая/Нумпад). Активация строки (клик или Enter/A) циклит значение, без выпадающих списков.
- Фон внутри рамки со списком — существо по уровню сложности: «Легкий» → кролик (`settings-bg-2`), «Тяжелый» → тролль (`settings-bg-1`, сверка с автором); переключается немедленно при цикле уровня (живое превью черновика).
- Семантика применения меняется с «немедленной» на диалог с черновиком: галочка применяет (уровень и первый ход — к следующей новой партии; раскладка — немедленно), крестик/Esc/B закрывает, отбрасывая изменения.
- Клавиатура/геймпад: вертикальная навигация по строкам списка и плиткам OK/X, подтверждение циклит значение или нажимает плиту.
- Старые пары чекбоксов и их стили удаляются.

## Capabilities

### New Capabilities
(нет)

### Modified Capabilities
- `game-ui`: требование «Окно «Настройки»» переписывается под новую структуру и семантику (список, циклы, черновик, OK/X, существо по сложности).
- `game-input`: требование «Полная навигация по интерфейсу» — навигация по настройкам меняется с чекбоксов на строки списка и плиты; Esc/B закрывает настройки с отменой.

## Impact

- Правятся: `web/index.html` (разметка диалога), `web/css/style.css` (новые стили, удаление чекбоксов), `web/js/ui.js` (draft-модель, циклы, OK/X, превью фона, навигация), `tools/ui_smoke.js` (тесты настроек переписываются).
- Ассеты не добавляются: существа — существующие `settings-bg-1/2`; плиты и рамка — CSS в стиле референсов.
- `references/` — справочные скриншоты, в поставку (`web/`) не идут.
- Спека «немедленного применения раскладки» меняется на применение по галочке (сценарий обновляется).
