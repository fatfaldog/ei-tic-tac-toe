# Spec Delta

## MODIFIED Requirements

### Requirement: Окно «Настройки»
Игра SHALL предоставлять окно «Настройки» в стиле диалогов «Проклятых Земель» в пределах игрового поля: плита-заголовок «Настройки», ниже рамка со списком настроек вида «название → текущее значение» (Уровень сложности, Кто ходит первым, Раскладка 1-9), внизу плиты с галочкой и крестиком. Активация строки SHALL циклить значение между двумя вариантами. Фон рамки — существо по уровню сложности черновика: «Легкий» — кролик, «Тяжелый» — тролль. Галочка применяет черновик и закрывает окно; крестик и Esc/B закрывают окно без применения.

#### Scenario: Открытие настроек
- **WHEN** выбран пункт меню «Настройки»
- **THEN** открывается окно с плитой «Настройки», рамкой со списком из трёх строк и плитками галочки и крестика внизу

#### Scenario: Взаимоисключающий выбор уровня
- **WHEN** строка «Уровень сложности» циклится активацией
- **THEN** активен ровно один вариант — «Легкий» или «Тяжелый», без выпадающего списка

#### Scenario: Взаимоисключающий выбор раскладки
- **WHEN** строка «Раскладка 1-9» циклится активацией
- **THEN** активен ровно один вариант — «Читающая» или «Нумпад»

#### Scenario: Применение настроек
- **WHEN** в окне изменён уровень сложности и/или первый ход и нажата плита с галочкой
- **THEN** окно закрывается, следующая новая партия играет по изменённым настройкам

#### Scenario: Применение раскладки немедленно
- **WHEN** строка «Раскладка 1-9» циклится на «Нумпад» и нажата плита с галочкой
- **THEN** после закрытия окна клавиша 7 сразу выбирает верхнюю левую клетку

#### Scenario: Цикл значения строки
- **WHEN** активируется строка «Уровень сложности» со значением «Легкий»
- **THEN** значение меняется на «Тяжелый», повторная активация возвращает «Легкий»

#### Scenario: Существо по сложности
- **WHEN** в окне уровень сложности циклится с «Легкий» на «Тяжелый»
- **THEN** фон рамки со списком немедленно меняется с кролика на тролля, и наоборот

#### Scenario: Отмена по крестику
- **WHEN** изменены значения строк и нажата плита с крестиком (или Esc/B)
- **THEN** окно закрывается, все изменения отбрасываются: настройки остаются прежними
