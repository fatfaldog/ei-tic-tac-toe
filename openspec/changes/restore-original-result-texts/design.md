# Design

## Context

Допущение D8 изменения `port-krestiki-to-web` («поведение оригинала при победе/ничьей неизвестно, тексты придуманы») опровергнуто пользователем и подтверждено разбором: в `.data` секции exe по смещению `0x723e4` лежат cp1251-литералы PChar (парами, как Delphi дублирует константы): «Вы выиграли. ПоЗдравляю!!!!!», «Ничья!!!!», «Комп вас уделал :tease:». Первая разведка их пропустила: cp1251-скан обрывался после 40 совпадений, а первые сорок — мусор из заголовка секций. Решения пользователя: тексты — дословно; `:tease:` — отсылка к «колобкам» форума Nival, в web-версии заменяется на UTF-эмодзи; «ПоЗдравляю» — не опечатка, а врезанная аббревиатура ПЗ (как «по ПЗшному»), сохраняется как есть.

## Goals / Non-Goals

**Goals:**
- Оригинальные тексты исходов в игре и в извлекаемых данных (`layout.json`).
- Адаптация смайлика `:tease:` → 😜 только на этапе рендера, литерал в данных не искажается.
- Воспроизводимость: тексты извлекаются пайплайном из exe, а не зашиты руками.

**Non-Goals:**
- Правка архивных артефактов `port-krestiki-to-web` (допущение D8 остаётся в архиве как историческое; опровержение фиксируется здесь).
- Выбор эмодзи настраиваемым; иные строки (меню, настройки, «Об авторе») не трогаются — они уже аутентичны.

## Decisions

### D1. Извлечение литералов скриптом, поиск по содержательным маркерам
`tools/extract_assets.py` сканирует `.data` на cp1251-строки без обрыва по счётчику (урок первой разведки); мусор отсеивается требованием содержательных маркеров: в строку-кандидат должны попадать «выиграл»/«ичья»/«уделал» при декодировании cp1251, минимальная длина 8, и строка не должна состоять из паттерна «я»-шума. Найденные уникальные строки пишутся в `layout.json.resultTexts` с привязкой к исходам (`playerWon`, `computerWon`, `draw`) по маркерам: «выиграли» → победа, «уделал» → поражение, «ичья» → ничья. Дубликаты (Delphi хранит пары) схлопываются.

### D2. Подстановка эмодзи на этапе рендера, данные хранят литерал
`layout.json.resultTexts.computerWon` содержит аутентичный «Комп вас уделал :tease:»; `ui.js` при показе заменяет «:tease:» на «😜» (U+1F61C). Единственная точка подстановки — константа `RESULT_TEXTS` (тексты в ней соответствуют извлечённым; при смене данных в layout.json синхронизация — руками, как и остальные тексты, перегенерируемые из layout).

### D3. Выбор эмодзи: 😜 (U+1F61C)
Колобок «:tease:» с форума Nival — жёлтый шар с высунутым языком и подмигиванием. Из стандартных эмодзи ближе всего 😜 (лицо с языком и подмигиванием); альтернативы 😛 (без подмигивания — теряется дразнящий тон) и 😏 (ухмылка без языка) отклонены. Решение пользователя подтверждено.

## Risks / Trade-offs

- [Эмодзи не отрисуется на экзотической старой ОС] → fallback-глиф; все актуальные платформы (macOS/Windows/Android/iOS) U+1F61C поддерживают.
- [Маркерный поиск строк хрупок при других билдах exe] → скан дополняется прямым поиском байтового паттерна «:tease:» как страховкой; при неудаче пайплайн не падает — поле `resultTexts` просто отсутствует (тексты уже зафиксированы в спеке и тестах).

## Migration Plan

Три правки (extractor, ui.js, тесты) + перегенерация layout.json; откат — возврат прежней константы. Автопубликация на Pages сработает от изменений в `web/**`.
